# Частная школа «ГРАНИ» — Мобильное PWA-приложение

Официальное веб-приложение (PWA) для частной школы «ГРАНИ».
Предназначено для родителей, кураторов, педагогов дополнительного образования и администрации.

## Возможности приложения

- **Родительский кабинет**:
  - Расписание уроков и кружков;
  - Запись на кружки: пробное занятие со скидкой 50% и запись на основной курс;
  - Предупреждение об отсутствии или опоздании ребенка в 1 клик;
  - Баланс питания и выбор меню;
  - Прямая связь с куратором и администрацией.
- **Кабинет куратора**:
  - Журнал посещаемости с интеграцией СКУД;
  - Передача смены на продленку в 15:00 с фиксацией статуса выполнения домашних заданий;
  - Контроль питания и учет спецдиет (аллергии, БГ/БЛ).
- **Кабинет педагога ДО**:
  - Учет пробных и постоянных занятий;
  - Оплата строго по факту посещений;
  - Перевод учеников с пробного на постоянный курс или фиксация отказа.
- **Панель руководителя**:
  - Оперативная сводка за день: общая явка, число порций горячего питания, активные кружки, заявки на консультации;
  - Конструктор ступеней познания (7 официальных ступеней) с безопасным управлением.
- **Кухня и буфет**:
  - Точный подсчет порций к завтраку, обеду и полднику в реальном времени.

## Стек технологий

- **React 19**, **TypeScript**, **Vite**
- **Tailwind CSS v4**
- **Lucide React** (иконки)
- **PWA** (Service Worker, Web App Manifest, offline-first)
- **Синхронизация данных**: REST API с двусторонним обменом и автосохранением
